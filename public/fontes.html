🔌 Fontes de dados

Toda planilha, API e calendário de fora que alimenta o Office, das áreas que você abre. A data de cada uma é lida do próprio dado, nunca digitada. O que dá, o servidor atualiza sozinho; o resto vira lembrete pra dona.

Como funciona

  • Automática: o servidor busca sozinho, no prazo de cada uma. Uma planilha do OneDrive, SharePoint ou Google é baixada e passa pelo mesmo leitor do PC. Se ela não mudou, nada é reprocessado.
  • Curada à mão: alguém atualiza à mão. Quando passa do prazo de revisão, a dona recebe um lembrete. Conferiu e está certo? É só clicar em "Marcar como revisada".
  • ⏳ Aguarda você: falta algo que só uma pessoa faz, como colar o link da planilha ou pôr a chave da API no servidor. O que falta aparece no card.
  • Atrasou ou deu erro? Vira alerta para a área dona no sino e no relatório de segunda.
  • Fonte nova no Office entra primeiro no registro (routes/fontes.js). Um teste automático barra script de sync ou arquivo de dados que fique sem dono.
